# 🌊 Industrial Smart Turbidity Node (ESP32)

โหนดตรวจวัดความขุ่นน้ำอัจฉริยะด้วยบอร์ด **ESP32** ออกแบบมาสำหรับงานอุตสาหกรรม (Industrial IoT) รองรับการใช้งานหลายบอร์ดพร้อมกันด้วยโค้ดชุดเดียว (Multi-Node) จัดการการตั้งค่าและอัปเดตเฟิร์มแวร์ไร้สาย (OTA) ผ่าน **GitHub** และส่งข้อมูลขึ้นคลาวด์ **ThingsBoard**

## ⚙️ ฮาร์ดแวร์ที่ใช้
* **Microcontroller:** ESP32 NodeMCU (esp32dev)
* **Shield:** IOXESP32 Modbus RTU Shield
* **Sensor:** DFRobot Industrial Turbidity Sensor (SEN0671)
* **การเชื่อมต่อ:** Serial2 (RX = GPIO16, TX = GPIO17), Baud Rate 9600 8N1
* **ไฟเลี้ยง:** เซนเซอร์ใช้ไฟเลี้ยง 12V ร่วมกับชิลด์ (ส่วนบอร์ด ESP32 ใช้ไฟจาก USB/Adpater 5V)

---

## 🛠️ การติดตั้งและใช้งานครั้งแรก

### 1. แฟลชโค้ดและจด MAC Address
1. เปิดโปรเจกต์นี้ด้วย **VS Code + PlatformIO**
2. เสียบสาย USB และกดปุ่ม **Upload (➔)** ที่แถบด้านล่าง
3. เปิด **Serial Monitor (🔌)** เพื่อดู `MAC Address` ของบอร์ด (เช่น `246F287ABC12`) ให้จดค่านี้ไว้

### 2. ตั้งค่าบน GitHub (config.json)
1. ไปที่ไฟล์ `config.json` ใน Repository นี้
2. แก้ไขไฟล์โดยใส่ **MAC Address** ของคุณแทนที่ตัวอย่าง
3. ใส่ **ThingsBoard Token** ของอุปกรณ์
4. กำหนดเวลา **sleep_minutes** (รอบเวลาตื่นมาส่งข้อมูล เช่น 15 นาที)
5. บันทึก (Commit) การเปลี่ยนแปลง

### 3. ตั้งค่า WiFi ให้บอร์ด (ทำเฉพาะครั้งแรกหรือเปลี่ยนสถานที่)
1. เปิดบอร์ด ESP32 มันจะพยายามหา WiFi หากไม่พบจะปล่อย Hotspot ชื่อ **`TurbidityNode_AP`**
2. นำสมาร์ทโฟนเชื่อมต่อ WiFi ชื่อดังกล่าว
3. หน้าเว็บจะเด้งขึ้นมาอัตโนมัติ ให้เลือก WiFi สถานที่ทำงานและใส่รหัสผ่าน
4. บอร์ดจะบันทึกรหัสผ่านไว้ถาวรและเริ่มการทำงานทันที

---

## 🔄 การทำงานของระบบ (Workflow)
ระบบถูกออกแบบมาให้ประหยัดทรัพยากรและเสถียรที่สุดด้วย FSM และ Deep Sleep:
1. **ตื่นนอน:** เชื่อมต่อ WiFi ที่เคยบันทึกไว้
2. **Sync GitHub:** โหลด `config.json` มาตรวจสอบ
   - หากเจอเวอร์ชันใหม่ จะทำ **OTA Update** อัตโนมัติ
   - โหลดการตั้งค่าเวลา Sleep และ Token ตาม MAC Address ของตัวเอง
3. **อ่านเซนเซอร์:** สื่อสารกับเซนเซอร์ผ่าน Modbus RTU
4. **ส่งข้อมูล:** ส่งข้อมูล ความขุ่นน้ำ (Turbidity) และ ความแรง WiFi (RSSI) ไปยัง ThingsBoard
5. **หลับ (Deep Sleep):** ปิดการทำงานตัวเองตามเวลาที่ตั้งไว้ เพื่อป้องกันความร้อนและรีเซ็ต RAM ให้เสถียร 100%

---

## 🚀 การทำ OTA Update (อัปเดตโค้ดไร้สาย)
หากต้องการแก้บั๊กหรือเพิ่มฟีเจอร์ให้บอร์ดทุกตัวพร้อมกัน:
1. แก้ไขเลข `#define CURRENT_VERSION` ในไฟล์ `include/app_config.h` ให้สูงขึ้น (เช่น จาก `"1.0.0"` เป็น `"1.0.1"`)
2. กด **Build (✔)** ใน PlatformIO
3. นำไฟล์ `.pio/build/esp32dev/firmware.bin` ไปสร้าง **Release** บน GitHub (ตั้ง Tag ให้ตรงกัน เช่น `v1.0.1`)
4. ขั้นตอนสุดท้าย ไปแก้ไฟล์ `config.json` เป็น `"version": "1.0.1"`
*เมื่อบอร์ดตื่นขึ้นมารอบหน้า มันจะดาวน์โหลดโค้ดใหม่ไปติดตั้งเองอัตโนมัติ!*
